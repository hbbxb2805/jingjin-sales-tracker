## 数据说明

- 共 423 个单位条目，其中 365 个查到官方公示电话。
- 电话来源仅采信 `*.gov.cn` 官网、单位官网、财政部政府采购网、省级厅局及官方媒体。
- **黄页、顺企网、爱企查、114 等第三方来源的号码一律剔除**，官网未公示的留空，不做任何推测。
- 区县商务主责机构实际分四类：独立商务局（泊头、运河、新华）／商务与工信科技合并设局（10 个）／发改局加挂商务职能（南皮、吴桥、孟村）／园区经发局（经开区、高新区）。
